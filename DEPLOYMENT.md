# Деплой AI Productivity Tracker

Этот проект готовится к связке Vercel + Neon PostgreSQL.

## Что будет работать публично

- регистрация и вход по email и паролю;
- создание, редактирование и удаление задач;
- запуск и сохранение фокус-сессий;
- аналитика и фокус-профиль на основе сохранённых данных.

AI-рекомендации зависят от выбранного LLM-провайдера. Для первого публичного деплоя можно поставить `LLM_PROVIDER="disabled"`: основные функции будут работать, а кнопка рекомендаций покажет понятное сообщение. Для бесплатной демонстрации AI локально используется Ollama, но Vercel не сможет обращаться к Ollama на ноутбуке пользователя.

## 1. Создать базу в Neon

1. Откройте Neon и создайте новый проект.
2. Скопируйте строку подключения PostgreSQL.
3. Выбирайте строку с `sslmode=require`.

Пример формата:

```env
DATABASE_URL="postgresql://USER:PASSWORD@HOST/DB?sslmode=require"
```

## 2. Настроить переменные окружения в Vercel

В проекте Vercel откройте `Settings -> Environment Variables` и добавьте:

```env
DATABASE_URL="строка подключения Neon"
JWT_SECRET="длинная случайная строка"
LLM_PROVIDER="disabled"
OLLAMA_BASE_URL="http://localhost:11434"
OLLAMA_MODEL="llama3.2"
```

Для первого публичного деплоя без AI лучше поставить:

```env
LLM_PROVIDER="disabled"
```

Для локальной демонстрации AI через Ollama:

```env
LLM_PROVIDER="ollama"
OLLAMA_BASE_URL="http://localhost:11434"
OLLAMA_MODEL="llama3.2"
```

Для внешнего LLM-провайдера:

```env
LLM_PROVIDER="external"
EXTERNAL_LLM_API_URL="https://provider.example.com/v1/chat/completions"
EXTERNAL_LLM_API_KEY="ключ провайдера"
EXTERNAL_LLM_MODEL="название модели"
```

Для `JWT_SECRET` можно использовать любую длинную случайную строку. Например, сгенерировать локально:

```bash
openssl rand -base64 32
```

## 3. Деплой на Vercel

При деплое Vercel выполнит команду:

```bash
npm run vercel-build
```

Она:

1. генерирует Prisma Client;
2. применяет миграции к Neon через `prisma migrate deploy`;
3. собирает Next.js-приложение.

После успешного деплоя Vercel выдаст публичную ссылку.

## 4. Локальная проверка с облачной базой

В локальный `.env` можно временно поставить тот же `DATABASE_URL` из Neon, затем выполнить:

```bash
npm run prisma:deploy
npm run dev
```

После этого локальное приложение будет работать с той же облачной базой.

## 5. Что говорить про AI-модуль на защите

В тексте курсовой указан AI-модуль на основе внешней LLM-модели или OpenAI API. В реализации модуль вынесен за переменную `LLM_PROVIDER`: приложение хранит запросы, статусы AI-запросов, фокус-профиль и рекомендации в базе, а конкретный провайдер LLM подключается отдельно.

Для демонстрации без платных API используется Ollama с локальной LLM-моделью. Это позволяет показать работу AI-рекомендаций без оплаты и без передачи данных пользователя в платный внешний сервис. В публичном деплое основные функции приложения работают через Vercel + Neon, а AI-модуль может быть подключён к любому доступному LLM-провайдеру при наличии ключа или отдельного сервера с моделью.
